# 설교문 넣는 곳

이 폴더에 설교문 파일을 올리시면 **곧바로 자동으로 요약해서 홈페이지 설교란에 올립니다.**
(파일을 올린 순간 GitHub Actions 의 「설교문 자동 요약·등록」이 돌아갑니다. 보통 1~2분 걸립니다.)

## 올리는 방법

1. GitHub 저장소 웹 화면에서 이 `sermons-src` 폴더로 들어갑니다.
2. **Add file → Upload files** 를 누르고 설교문을 끌어다 놓습니다.
3. 아래로 내려 **Commit changes** 를 누르면 끝입니다.

`.txt` · `.md` · `.docx` 를 읽을 수 있습니다. 한글(.hwp) 파일은 읽지 못할 수 있으니,
한글에서 "다른 이름으로 저장 → 서식 없는 텍스트(.txt)" 로 저장해 올려 주시면 확실합니다.

## 파일에 꼭 들어가야 하는 것

설교문 안에 **본문 장절**이 있어야 어느 성경 책으로 분류할지 정할 수 있습니다.
파일 이름이나 첫 줄에 이렇게 적어 주시면 가장 좋습니다.

```
본문: 로마서 8:31-39
제목: 끊을 수 없는 사랑
시리즈: 로마서 강해
```

본문 장절을 찾지 못한 파일은 올리지 않고 따로 여쭙습니다.

## 요약은 어떻게 만들어지나요

원고의 짜임(**제목 / 본문 / 서론 / 본론 1·2·3 / 결론 / 찬송**)을 그대로 읽어서
제목·본문·요약·말씀의 흐름·맺는 말씀을 뽑아냅니다. 인터넷이나 AI 없이도 동작합니다.

저장소 **Settings → Secrets → Actions** 에 `ANTHROPIC_API_KEY` 를 넣어 두시면,
AI 가 그 요약의 문장을 한 번 더 다듬습니다(선택). 키가 없으면 규칙 기반 요약만 씁니다.

컴퓨터에서 직접 확인해 보고 싶으실 때는 이렇게 하시면 됩니다.

```
node scripts/import-sermons.js --dry     # 등록하지 않고 결과만 보기
node scripts/import-sermons.js           # 실제로 등록
node scripts/import-sermons.js --force   # 같은 본문이 이미 있어도 새 요약으로 교체
```

관리자 화면(`admin.html`)의 **설교** 탭에서 원고를 붙여 넣어도 같은 요약이 나옵니다.

## 올라간 뒤에는

요약 결과는 `sermons.json` 에 저장되고, 홈페이지 「설교 말씀」과 아카이브에
**성경 책 이름별 · 성경 차례순**으로 표시됩니다. 여기 원본 파일은 지우셔도 됩니다
(이미 등록된 설교는 파일이 남아 있어도 다시 올리지 않습니다).
