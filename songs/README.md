# 찬양

이 폴더에 노래 파일을 넣으면 홈페이지 **찬양**에 저절로 올라갑니다.

## 넣는 법

1. 깃허브에서 이 `songs` 폴더를 엽니다.
2. 넣고 싶은 갈래 폴더(예: `자작 찬양`)를 누릅니다.
3. 오른쪽 위 **Add file → Upload files** 를 누르고 파일을 끌어다 놓습니다.
4. 아래 **Commit changes** 를 누르면 1~2분 뒤 홈페이지 찬양에 나옵니다.

## 폴더가 곧 갈래입니다

폴더 이름이 찬양 페이지의 갈래 이름이 됩니다.

| 폴더 | 쓰임 |
| --- | --- |
| `자작 찬양` | 직접 만드신 곡 |
| `찬송가` | 찬송가 |
| `교회학교` | 어린이 찬양 |

새 갈래를 만들고 싶으시면 `Add file → Create new file` 에서
`새폴더이름/.gitkeep` 이라고 적고 저장하시면 됩니다.

## 파일 이름이 곡목입니다

`주의 은혜라.mp3` 처럼 곡목 그대로 올려 주세요.

- 앞에 날짜를 적으면 날짜로도 표시됩니다 — `2026-08-30 주의 은혜라.mp3`
- 뒤에 ` - 만든이` 를 붙이면 만든이가 따로 나옵니다 — `주의 은혜라 - 류선희.mp3`
- 둘 다 쓰셔도 됩니다 — `2026-08-30 주의 은혜라 - 류선희.mp3`

띄어쓰기 있는 **하이픈** 앞뒤로만 나뉘므로, 곡목 안의 하이픈은 그대로 남습니다.

## 가사 넣기

노래 파일 옆에 **이름이 똑같은 `.txt` 파일**을 올리면 찬양 페이지에
「가사」 단추가 생기고, 누르면 곡 아래에 가사가 펼쳐집니다.

```
자작 찬양/모세의 노래.mp3
자작 찬양/모세의 노래.txt   ← 가사
```

- 깃허브에서 `Add file → Create new file` 을 누르고 이름 칸에
  `모세의 노래.txt` 처럼 노래와 같은 이름을 적은 뒤 가사를 붙여 넣으면 됩니다.
- 적은 줄바꿈과 빈 줄(절 사이)은 그대로 보입니다.
- 가사를 고치려면 그 `.txt` 만 고쳐 저장하시면 1~2분 뒤 바뀝니다.

## 파일 형식과 크기

`.mp3` 를 권합니다. `.m4a` · `.ogg` · `.wav` 도 됩니다.

**한 곡에 10MB 를 넘기지 마세요.** 5분짜리 MP3 가 128kbps 로 약 5MB 입니다.
수노(Suno)에서 받으신 파일은 대개 그 안에 들어옵니다.

## 올리기 전에 확인해 주세요

**깃허브는 지운 파일도 이력에 영원히 남깁니다.** 노래를 바꿔 올리면
옛 파일도 그대로 남아 용량이 두 배가 됩니다. 최종본인지 한 번 보시고
올려 주세요.

**저작권** — 직접 만드신 곡과 찬송가(대부분 저작권이 풀렸습니다)는
문제없습니다. 요즘 CCM·복음성가 음원은 공개 홈페이지에 올릴 때
이용허락이 필요할 수 있으니, 그런 곡은 먼저 알려 주세요.

## 유튜브 찬양 재생목록 넣기

유튜브에 있는 찬양 재생목록을 찬양 페이지 맨 위에서 바로 들을 수 있게 할 수 있습니다.

1. 이 폴더의 **`유튜브.txt`** 를 열고 연필(✏️) 단추를 누릅니다.
2. 한 줄에 하나씩 `제목 | 주소` 로 적습니다.
   - 재생목록: 유튜브에서 재생목록을 열고 **공유 → 복사**한 주소 (`…list=PL…` 이 들어 있는 주소)
   - 영상 하나: 영상 주소 (`youtu.be/…` 또는 `watch?v=…`)
3. **Commit changes** 를 누르면 1~2분 뒤 찬양 페이지에 나옵니다.

```
주일 예배 찬양 | https://www.youtube.com/playlist?list=PLxxxxxxxx
어린이 찬양 | https://www.youtube.com/playlist?list=PLyyyyyyyy
```

노래 파일을 우리 홈페이지에 올리는 것이 아니라 **유튜브에서 그대로 틀어 주는 것**이라
저작권 걱정이 덜합니다. 다만 영상 주인이 「퍼가기」를 막아 둔 영상은 찬양 페이지 안에서
재생되지 않고, 「유튜브에서 열기」로만 들을 수 있습니다.
