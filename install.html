오늘의 말씀을
휴대폰 첫 화면에 놓아 보세요

한 번만 해 두면, 앱처럼 아이콘 하나 누르면 바로 오늘 말씀이 열립니다. 1분이면 됩니다.

동산 말씀
설치하면 휴대폰 첫 화면에 이 「동산 말씀」 아이콘이 생깁니다.
돈이 들지 않고, 가입도 비밀번호도 없습니다.
✅ 이미 설치되어 있어요지금 아이콘으로 열어 보고 계십니다. 따로 하실 일이 없습니다. 📖 오늘의 말씀 보기
⚠️ 카카오톡 안에서는 설치가 안 돼요먼저 아래 단추를 눌러 인터넷 앱(사파리·삼성 인터넷·크롬)으로 이 화면을 다시 여세요. 🌐 인터넷 앱으로 열기 단추가 안 되면: 카톡 화면 오른쪽 아래(아이폰) 또는 오른쪽 위(갤럭시)의 ⋮ 나 ⬆ 를 누르고 「다른 브라우저로 열기」를 고르세요.
👍 이 휴대폰은 바로 설치할 수 있어요아래 단추를 누르고, 나오는 창에서 설치 를 누르세요.
내 휴대폰을 골라 주세요

🍎 아이폰에 설치하기

1
사파리(파란 나침반 🧭)로 이 화면을 엽니다. 카카오톡이나 네이버 앱 안에서는 설치가 안 됩니다. 꼭 사파리로 여세요.
2
화면 맨 아래에 있는 SHARE 공유 단추를 누릅니다.
‹›SHAREI📖⧉
맨 아래 단추가 안 보이면 화면을 살짝 아래로 내려 보세요. 아래쪽에 ··· 만 보이면 그것을 누른 뒤 SHARE 공유 를 누르세요.
3
나온 목록을 손가락으로 위로 밀어 올려 PLUS 홈 화면에 추가 를 누릅니다.
4
오른쪽 위의 추가 를 누르면 끝입니다! 🎉

🌐 갤럭시(삼성 인터넷)에 설치하기

1
삼성 인터넷(보라색 행성 🪐)으로 이 화면을 엽니다.
2
화면 맨 아래 오른쪽 MENU 메뉴 를 누릅니다.
‹›⌂⧉MENUI
주소창 옆에 DOWN 설치 단추가 보이면, 그것을 눌러도 바로 설치됩니다.
3
PLUS 현재 페이지 추가 를 누르고, 홈 화면 을 고릅니다.
4
추가 를 누르면 끝입니다! 🎉

🟢 크롬으로 설치하기

1
크롬(빨강·노랑·초록 동그라미)으로 이 화면을 엽니다.
2
화면 오른쪽 위의 DOTS (점 세 개)를 누릅니다.
DOTSI
3
PLUS 홈 화면에 추가 또는 DOWN 앱 설치 를 누릅니다.
4
설치 또는 추가 를 누르면 끝입니다! 🎉
🎉 설치가 끝나면 휴대폰 첫 화면에서 「동산 말씀」 아이콘을 찾아 누르세요.
매일 아침 5시에 새 말씀이 올라옵니다. 글씨가 작으면 큰 글씨 화면을 쓰시면 됩니다.
어려우시면 예배 뒤 안내석에 휴대폰을 가져오세요. 한 번 해 드리면 끝입니다.

  3. PLUS 현재 페이지 추가 → 홈 화면
  4. 추가
