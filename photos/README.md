# 사진첩

이 폴더에 사진을 넣으면 홈페이지 **사진첩**에 저절로 올라갑니다.

## 넣는 법

1. 깃허브에서 이 `photos` 폴더를 엽니다.
2. 넣고 싶은 카테고리 폴더(예: `2026-보물캠프`)를 누릅니다.
3. 오른쪽 위 **Add file → Upload files** 를 누르고 사진을 끌어다 놓습니다.
4. 아래 **Commit changes** 를 누르면 1~2분 뒤 홈페이지 사진첩에 나옵니다.

## 폴더가 곧 카테고리입니다

폴더 이름이 사진첩의 카테고리 이름이 됩니다. 새 카테고리를 만들고 싶으시면
`Add file → Create new file` 에서 `새폴더이름/.gitkeep` 이라고 적고 저장하시면 됩니다.

`담임목사` 폴더는 특별합니다. 여기에 `인사말.jpg` 라는 이름으로 사진을 넣으시면
교회소개의 **담임목사 인사말** 자리에 연필 스케치 느낌으로 들어갑니다.

## 사진 이름

파일 이름이 사진 설명으로 쓰입니다. `여름성경학교 단체사진.jpg` 처럼
알아보기 쉬운 이름으로 올려 주세요. 이름 앞에 `2026-07-21` 처럼 날짜를 적으시면
날짜로도 표시됩니다.

## 올리기 전에 한 번 살펴 주세요

사진첩은 누구나 볼 수 있는 공개 홈페이지입니다. 특히 어린이와 청소년이 나온 사진은
가정에서 동의를 받으신 것만 올려 주시기를 부탁드립니다.
